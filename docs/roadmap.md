# Roadmap

Audit integrity now includes package-instance finding identities, scanner-response validation, snapshot secret scanning, explicit incomplete coverage, cross-scanner remediation groups and evidence-backed advisory aliases. Release builds embed the pinned native CPU runtime. Local audits enable inference by default; cluster workers share a pre-provisioned model across concurrent jobs. Inference is still an automatically managed loopback subprocess, not an in-process model engine. Model preparation and generation are bounded, and report metadata exposes review coverage and token usage. Semantic security accuracy and optimal thread/slot settings still require workload-specific evaluation.

Implemented in this snapshot: foundational Go CLI and interactive setup; SQLite schema and content-addressed artifacts; canonical workflow compilation and tamper validation; bounded concurrent local execution; authenticated whole-audit cluster submission and renewable worker leases; Docker Compose and Helm packaging with offline workers; Opengrep/Syft/Grype/Gitleaks/Poutine/OPA/OSV-Scanner/Checkov/Kubescape adapters; JSON/SARIF/HTML reports; typed evidence allowlists and exact source-location graph edges; CPU hardware inspection and recommendations; digest-verified model download and ephemeral loopback `llama.cpp` lifecycle; strict invariant validation; CLI end-to-end coverage; checksum-pinned repository tool provisioning; and real Opengrep/Syft and Poutine execution paths.

Next: cluster idempotency keys, OIDC, object storage, and a Kubernetes `SecurityAudit` controller; local checkpoint/resume; typed task I/O schemas and `${tasks.*}` reference checking; richer SBOM/package/image/RBAC graph correlation; verification strategies and state transitions; inference response cache commands; richer managed-model selection and lifecycle commands; positive/negative authorization demo; benchmark harness; remaining OS sandbox controls; import/export; pinned real-scanner CI for the newer adapters; and Windows CI.

Later: task-level distributed fan-out, capability-aware placement, NATS transport if operational testing justifies it, and security-knowledge compilation after validation/approval controls exist.
